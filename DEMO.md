# QStock — сценарий демонстрации для руководства

База наполняется автоматически при первом запуске (`seedIfEmpty`) — все экраны
уже с данными: 5 точек, история смен за 9–14 дней, продажи, движения, заявки,
задачи, заметки, инвентаризации, уведомления и журнал действий.

## Учётные записи

| Роль | Логин | Пароль | Что показать |
|------|-------|--------|--------------|
| Администратор | `admin` | `admin123` | Дашборд, аналитика, KPI, справочники, журнал |
| BRE (закупщик) | `bre` | `bre123` | Свои точки, закуп, заявки, задачи |
| BRE №2 | `bre2` | `bre123` | Вторая зона ответственности (Riverside, Mega Planet) |
| SE (продавец) | `nikita` | `se123` | Моя смена на точке Compass, заметки, задачи |
| SE | `timur` | `se123` | ТРЦ Riverside — критически низкий остаток |

Другие продавцы (все `se123`): `georgiy`, `anna`, `milana`, `dmitry`, `sardor`,
`kamila`, а также `se`/`se2` (ТТ Центральная). Есть заблокированный
сотрудник `exse` — для демонстрации управления доступом.

## Точки

| Точка | BRE | Состояние — что демонстрирует |
|-------|-----|-------------------------------|
| ТТ Центральная | Иванов | Открытая смена, история, инвентаризация в прошлом |
| Compass | Иванов | 14 дней истории, 2 команды 2/2, заявки, заметки, задачи |
| ТРЦ Riverside | Ковалёв | **Критически низкий остаток** → «везти срочно», расчёт закупа |
| Chorsu Bazaar | Иванов | **Незакрытая смена со вчера** (overdue) на дашборде |
| Mega Planet | Ковалёв | **Требуется инвентаризация**, запланированная проверка |

## Рекомендуемый маршрут показа (10–15 минут)

1. **Админ · Дашборд** — KPI (открытые смены, продажи, сумма, стоимость остатков),
   плашка «Критически низкий остаток · везти срочно», «Незакрытые смены», таблица
   точек, графики продаж/остатков/рейтинга.
2. **Админ · Аналитика / KPI** — фильтры по датам, продажи по SKU, KPI по SE и BRE.
3. **Админ · Справочники** — SKU и цены (история цен), пользователи (в т.ч.
   заблокированный), категории и вкладки главной страницы SE.
4. **Админ · Журнал действий** — аудит операций (вход, изменение цены, решения по
   заявкам, закрытие смены, инвентаризация).
5. **BRE (`bre`) · Закуп** — расчёт потребности по одной точке и по всем сразу,
   подсветка критических позиций.
6. **BRE · Заявки** — согласование списаний/возвратов (есть ожидающие решения).
7. **BRE · Задачи** — постановка задачи на точку, комментарии SE, статусы.
8. **SE (`nikita`) · Моя смена (Compass)** — таблица «утро → продано → вечер» с
   мгновенным пересчётом, вкладки категорий, экспорт отчёта, заметки, задачи.
9. **SE (`timur`) · ТРЦ Riverside** — видно низкий остаток; оформить списание/возврат
   с отправкой на согласование BRE.
10. **Реальное время** — открыть админ-монитор и SE-смену в двух окнах: продажа у SE
    сразу отражается у BRE/админа.

## Сброс данных

Демо-данные пересоздаются на пустой базе. Чтобы начать с чистой демонстрации,
удалите файл БД (путь в `QSTOCK_DB`, по умолчанию `data/qstock.db`) и перезапустите
сервер — сидирование выполнится заново.
