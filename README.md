# QStock — CRM учёта остатков и продаж

Внутренняя CRM-система для контроля остатков, продаж, смен и онлайн-мониторинга
торговых точек (до 100 сотрудников). MVP по техническому заданию.

## Стек

- **Backend:** Node.js + Express
- **БД:** SQLite (`better-sqlite3`), полная история операций
- **Realtime:** Socket.IO (онлайн-обновление без перезагрузки)
- **Auth:** JWT (cookie) + bcrypt, ролевая модель
- **Frontend:** SPA на vanilla JS, светлая минималистичная тема в стиле IQOS,
  адаптивная вёрстка (ПК и планшеты)

## Запуск

```bash
npm install
npm run seed     # демо-данные (пользователи, точка, SKU)
npm start        # http://localhost:3000
```

Демо-учётки: `admin/admin123`, `bre/bre123`, `se/se123`, `se2/se123`.

## Роли

| Роль | Возможности |
|------|-------------|
| **ADMIN** | Пользователи, роли, точки, SKU, цены, смены (открытие/закрытие/разблокировка/принудительное закрытие), аналитика, KPI, журнал действий, плановые инвентаризации, настройки |
| **BRE** | Только свои точки: онлайн-мониторинг, просмотр закрытых смен, назначение инвентаризации, аналитика и KPI по своим точкам |
| **SE** | Своя точка (макс. 2 SE на точку): открытие смены (перенос остатков / ручной ввод), приход, списание, продажи (поштучно/суммарно), инвентаризация, закрытие смены |

## Реализованные модули ТЗ

- Подключение SE к точке с лимитом и точным сообщением о превышении
- Открытие смены: перенос остатков со вчера **или** ручной утренний остаток
- Автоматический расчёт текущего остатка: `нач + приход − продажи − списание`
- Онлайн-отображение остатков, продаж, стоимости (WebSocket)
- Закрытие смены с итоговой сводкой; закрытая смена не редактируется
- Инвентаризация: назначение (BRE/Admin/плановая), проведение (SE),
  блокировка закрытия смены, запись старых/новых значений
- Справочник SKU (только Admin), включение/отключение, мин. остаток
- История цен SKU, продажи фиксируются по цене на момент продажи
- История движения каждого SKU (журнал операций, скоуп по роли)
- Аналитика: виджеты, таблица по точкам, графики, фильтры, экспорт в Excel (CSV)
- Дашборд KPI: SE / BRE / точка
- Журнал действий (аудит) с пользователем, временем, IP, старым/новым значением
- Уведомления: критически низкий остаток, незакрытые смены, назначенная инвентаризация
- Плановые инвентаризации (ежедневно/еженедельно/ежемесячно/вручную) + планировщик

## Структура

```
server/
  index.js        Express + Socket.IO + статика
  db.js           Схема SQLite
  auth.js         JWT / bcrypt / middleware
  access.js       Видимость точек по ролям
  stock.js        Движения, low-stock, broadcast
  scheduler.js    Плановые инвентаризации, просроченные смены
  routes/         users, skus, points, shifts, inventory, analytics, misc
public/           index.html, styles.css, app.js (SPA)
```

## Переменные окружения

- `PORT` — порт (по умолчанию 3000)
- `QSTOCK_SECRET` — секрет JWT (обязательно сменить в проде)
- `QSTOCK_DB` — путь к файлу БД
